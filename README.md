# cmduick updates

Public distribution channel for **[cmduick](https://github.com/Quepuick/cmduick)** — a VS Code / Cursor extension (npm, Composer & Symfony command hub).

Source code lives in the private repo `Quepuick/cmduick`. This repo only hosts **VSIX releases**.

## Install

1. Open the [latest release](https://github.com/Quepuick/cmduick-updates/releases/latest)
2. Download `cmduick-*.vsix`
3. In Cursor / VS Code: **Command Palette** → `Extensions: Install from VSIX…`

The extension can also check this repo for updates (`cmduick.updateCheck`).
